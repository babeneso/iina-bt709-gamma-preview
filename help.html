BT.709 Gamma Preview

Switch the playback gamma of BT.709 SDR video, so you can compare how the same video looks with different gammas without leaving the player.

Required setting

Enable Load ICC profile in Settings… → Video → Color and HDR to display the video correctly.

When playing supported video (BT.709) with Load ICC profile disabled, the plugin displays a reminder dialog. It does not change your settings.

Using the plugin

Choose a playback gamma from Plugin → BT.709 Gamma Preview in the menu bar. Choose Show Details in Plugins Panel to see the same choices in IINA’s sidebar.

Keyboard shortcuts

Shortcut Action
⌃ ⌥ 0 BT.1886 (mpv Default)
⌃ ⌥ 1 Gamma ≈1.961 (QuickTime-like)
⌃ ⌥ 2 Gamma 2.2
⌃ ⌥ 3 Gamma 2.4
⌃ ⌥ G Show Details in Plugins Panel

Default gamma and playback windows

Change the default playback gamma in Settings… → Plugins → BT.709 Gamma Preview → ⓘ button. The initial default is BT.1886 (mpv Default).

New windows use this default. Each window keeps its own mode, even when you open another video in it.

Supported video and preview limits

The plugin works with video that IINA identifies as BT.709 SDR. Videos without color information, including some Log footage, may also be identified as BT.709.

For other video, such as HDR, the plugin changes nothing and shows Not Applicable to This Video.

QuickTime-like is an approximation, not an exact match of QuickTime. Results also depend on your display and playback settings, and the plugin does not calibrate your display.

Required permissions

IINA asks for Access the file system permission because the plugin needs it to adjust the gamma. The plugin doesn’t read or write your files, run other programs, or connect to the internet.
